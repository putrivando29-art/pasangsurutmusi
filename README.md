# Bilangan Bulat Sungai Musi

Media pembelajaran berbasis web untuk Matematika kelas VII (Fase D), materi **Bilangan Bulat**. Konteksnya adalah pasang surut Sungai Musi di Palembang. Papan duga (peil schaal) di tepi sungai dipakai sebagai jembatan dari pengalaman nyata ke garis bilangan.

Media ini dirancang untuk pembelajaran **asinkronus**: murid membuka tautan dari Google Classroom, belajar mandiri bersama LKPD, lalu menempelkan ringkasan hasil belajarnya ke tugas di Google Classroom.

Dokumen pendamping:

- [Lampiran 1. Rancangan Aktivitas Web Interaktif](docs/lampiran-1-rancangan-aktivitas-web-interaktif.md)

### 1.2 Capaian dan tujuan pembelajaran

Penggalan CP yang dipakai: membaca, menulis, dan membandingkan bilangan bulat. Sub penggalan: membandingkan bilangan bulat.

| TP | Rumusan di RPM | Bukti ketercapaian di RPM | Tahap di media |
|---|---|---|---|
| TP 1 | Peserta didik mampu menentukan letak bilangan bulat pada garis bilangan dengan tepat. | Murid dapat menentukan letak bilangan bulat dan menempatkannya secara tepat pada garis bilangan. | Tahap 1: Letak |
| TP 2 | Dengan bantuan garis bilangan, peserta didik mampu membandingkan nilai dua bilangan bulat menggunakan simbol matematis (<, >, =) dengan benar. | Murid dapat membandingkan nilai dua bilangan bulat dan menuliskannya menggunakan simbol (<, >, atau =) melalui bantuan garis bilangan. | Tahap 2: Bandingkan |
| TP 3 | Peserta didik mampu mengurutkan beberapa bilangan bulat dari yang terkecil ke terbesar atau sebaliknya berdasarkan hasil perbandingan dengan tepat. | Murid dapat mengurutkan beberapa bilangan bulat dan menyusunnya dari yang terkecil ke terbesar atau sebaliknya berdasarkan hasil perbandingan. | Tahap 3: Urutkan |

Operasi hitung (penjumlahan dan pengurangan) **tidak** termasuk tujuan pertemuan ini, sehingga fitur operasi hitung dari versi awal sudah dihapus.

## 3. Penilaian dan pelaporan

- **Tahap 1 sampai 3**: yang dicatat hanya **percobaan pertama** setiap soal. Murid tetap boleh mencoba lagi sampai benar. Pada Tahap 2, satu soal dihitung benar jika simbol dan alasannya sama-sama benar pada percobaan pertama.
- **Bantuan bertahap**: setelah dua kali salah, media menampilkan jawaban atau petunjuk letak supaya murid tidak macet.
- **Latihan penguatan**: skor dihitung per TP (masing-masing 3 soal). Jika benar kurang dari `MIN_BENAR_PER_TP` (saat ini 2), media menyarankan murid mengulang tahap TP tersebut.
- **Kriteria ketercapaian belum ada di RPM.** Bagian G (Asesmen) di RPM masih kosong. Angka 2 dari 3 adalah keputusan desain sementara, bukan ketentuan RPM. Ubah di `src/components/PracticeStage.tsx`.
- **Ringkasan untuk Google Classroom** berisi nama, kelas, waktu, skor tahap per TP, skor latihan per TP, dan jawaban refleksi. Tombol "Salin hasil" memakai clipboard. Jika peramban memblokirnya, teks ringkasan tetap tampil dan bisa disalin manual.

### 3.1 Penyimpanan data

Tidak ada server atau basis data. Media hanya menyimpan nama, kelas, tahap terakhir, dan skor tahap di `localStorage` peramban (kunci `bilangan-bulat-musi-v2`). Akibatnya:

- data hanya ada di perangkat dan peramban yang dipakai murid;
- guru **tidak** menerima data otomatis, sehingga bukti belajar bergantung pada ringkasan yang ditempel murid di Google Classroom;
- jawaban latihan dan refleksi tidak disimpan; jika halaman dimuat ulang sebelum disalin, isinya hilang.

## 4. Konteks dan sumber fakta

Kesepakatan matematika di media:

- titik acuan papan duga = 0;
- di atas titik acuan = bilangan positif = di sebelah kanan 0 pada garis mendatar;
- di bawah titik acuan = bilangan negatif = di sebelah kiri 0.

Skala -5 m sampai +5 m adalah model untuk belajar. Fakta konteks yang ditampilkan di panel Panduan & Info beserta sumbernya:

| Fakta | Sumber |
|---|---|
| Sungai Musi berhulu di Pegunungan Bukit Barisan dan bermuara di Selat Bangka | [detikSumbagsel, "Berapa Panjang Sungai Musi? Simak 7 Faktanya"](https://www.detik.com/sumbagsel/berita/d-7915826/berapa-panjang-sungai-musi-simak-7-faktanya) |
| Tunggang pasang surut di muara Sungai Musi sekitar 0,46 m (perbani) sampai 3,42 m (purnama) | [Surbakti, Jurnal Penelitian Sains, FMIPA Universitas Sriwijaya](https://ejurnal.mipa.unsri.ac.id/index.php/jps/article/download/92/86) |
| Jembatan Ampera setinggi 11,5 m dari permukaan air, menara 63 m | [Balai KJTK, Ditjen Bina Marga PUPR](https://binamarga.pu.go.id/balai-kjtk/berita/pemeriksaan-bersama-menara-jembatan-ampera) |

Catatan verifikasi: ketiga sumber di atas dikutip dari ringkasan hasil pencarian karena halaman aslinya tidak dapat dibuka dari lingkungan pengembangan. Cocokkan dengan halaman aslinya sebelum media dipakai.

## 5. Menjalankan proyek

Kebutuhan: Node.js 22 (atau Bun).

```bash
npm install        # atau: bun install
npm run dev        # server pengembangan di http://localhost:3000
npm run lint       # pemeriksaan tipe TypeScript (tsc --noEmit)
npm run build      # hasil statis di folder dist/
npm run preview    # mencoba hasil build
```

Hasil `dist/` berupa file statis, sehingga bisa diunggah ke layanan hosting statis apa pun. Tautannya kemudian dibagikan lewat Google Classroom.

Teknologi: React 19, TypeScript, Vite, Tailwind CSS 4, ikon `lucide-react`, efek `canvas-confetti`. Efek suara dibuat langsung dengan Web Audio API (`src/utils/audio.ts`) dan bisa dimatikan dari tombol "Suara Aktif".

## 7. Batasan yang diketahui

1. Tidak ada pengiriman data ke guru; bukti belajar bergantung pada ringkasan yang ditempel murid.
2. Jawaban latihan dan refleksi hilang jika halaman dimuat ulang sebelum disalin.
3. Soal bersifat tetap (tidak diacak), sehingga murid bisa saling menyalin jawaban.
4. `package.json` masih memuat dependensi bawaan templat yang tidak dipakai kode (`@google/genai`, `express`, `dotenv`). Begitu pula `metadata.json` yang masih menyebut kemampuan Gemini. Keduanya tidak memengaruhi fungsi media.
5. Di layar HP, garis bilangan -10 sampai 10 lebih lebar dari layar dan perlu digeser; posisi awalnya dipusatkan di 0.

## 8. Riwayat perubahan dari versi awal

Versi awal berfokus pada **operasi penjumlahan dan pengurangan** (simulasi hujan dan surut, kalimat matematika, kuis), sedangkan TP pertemuan ini adalah menentukan letak, membandingkan, dan mengurutkan. Perubahan yang dilakukan:

- komponen operasi hitung dihapus: `MusiRiverMedia`, `SimulationStage`, `SymbolicStage`, `ContextStage`, `ComparisonStage`, `ChallengeQuiz`;
- alur diganti menjadi lima tahap yang masing-masing terikat ke satu TP;
- ditambahkan tahap mengurutkan, yang sebelumnya tidak ada;
- perbandingan dua dermaga pada waktu yang sama (selisih 2 sampai 3 m, tidak masuk akal untuk dua dermaga yang berhadapan) diganti perbandingan waktu pengamatan di satu tempat;
- tampilan "ruang kolong jembatan" yang dihitung dari rumus tanpa sumber dihapus;
- semua angka ketinggian air dibatasi pada skala model -5 sampai +5 dan diberi keterangan sebagai model;
- sumber fakta dicantumkan di panel Panduan & Info;
- papan duga dan garis bilangan dapat dipakai dengan papan ketik.
